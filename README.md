# Nome do Projeto

Projeto desenvolvido com fins de um estudo, como parte do aprendizado em
**React + TypeScript**, utilizando **Next.js**.

O projeto foi iniciado a partir da estrutura padrão gerada pelo Next.js
e está sendo utilizado como base para **prática, experimentação e evolução contínua**,
com o objetivo de consolidar conceitos modernos do ecossistema **React**.

## Objetivo do Projeto

- Praticar React com TypeScript em um ambiente real
- Entender a estrutura e os conceitos do Next.js (App Router, SSR/CSR, etc.)
- Trabalhar com autenticação e controle de acesso
- Criar e gerenciar estados de forma eficiente
- Evoluir boas práticas de organização e arquitetura de código

## Funcionalidades

A aplicação consiste em um sistema de gerenciamento de tarefas (To-Do List), com foco em simular um fluxo completo de uso real.

O sistema permite que usuários:

- Criem novas tarefas
- Editem tarefas existentes
- Excluam tarefas
- Marquem tarefas como públicas ou privadas
- Visualizem tarefas públicas de outros usuários
- Comentem em tarefas públicas
- Autentiquem-se utilizando login social (Google)

Além disso, o sistema conta com:

- Controle de acesso com autenticação
- Separação entre tarefas públicas e privadas
- Renderização dinâmica e condicional
- Estrutura baseada em componentes reutilizáveis

## Tecnologias Utilizadas

- Next.js
- React
- TypeScript
- HTML5
- CSS3

## Observações Importantes

- Este repositório **não representa um produto final**
- O foco do projeto é **aprendizado e prática**
- O código pode sofrer mudanças frequentes conforme novos conceitos são aplicados

